Edge-Compatible Spike Sorting & Latent State Decoder

Target Industry Profile: Neuralink, Blackrock Neurotech, Precision Neuroscience

1. System Architecture & Concept

Streaming 1D-CNN autoencoder for real-time spike detection and dimension reduction, paired with a Kalman filter latent state trajectory estimator.

2. Synthetic Bio-Data Engineering Strategy

32-channel extracellular voltage recordings (30 kHz) with superimposed bi-phasic action potential templates and pink noise.

3. Low-End LLM Prompt & Module Blueprint

  • Module 1: Synthetic MEA Generator: Generate 32-channel 30kHz neural stream with stochastic Poisson spike trains and baseline pink noise.
  • Module 2: 1D-CNN Spike Classifier: Implement lightweight PyTorch 1D-CNN autoencoder for spike waveform feature extraction.
  • Module 3: Real-Time Latent Trajectory Decoder: Build discrete-time Kalman Filter to decode 2D kinematics from spike rate bins.

4. Core Technical Starter Skeleton

import torch
import torch.nn as nn

class SpikeSortingCNN(nn.Module):
    def __init__(self, num_channels=32, latent_dim=16):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Conv1d(num_channels, 64, kernel_size=7, stride=2, padding=3),
            nn.BatchNorm1d(64),
            nn.ReLU(),
            nn.Conv1d(64, latent_dim, kernel_size=5, stride=2, padding=2),
            nn.AdaptiveAvgPool1d(1)
        )
    def forward(self, x):
        return self.encoder(x).squeeze(-1)
